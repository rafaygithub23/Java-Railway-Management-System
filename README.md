# Java Railway Management System

A JavaFX-based desktop application designed to manage basic railway operations, including passengers, trains, railway staff, tickets, and user accounts.

## Features

- Passenger management
- Train management
- Railway staff management
- Ticket booking and management
- User authentication
- Admin functionality
- File-based data storage
- JavaFX graphical user interface
- Exception handling

## Technologies Used

- Java
- JavaFX
- Object-Oriented Programming
- File Handling
- Exception Handling
- IntelliJ IDEA
- JavaFX SDK

## Project Purpose

The project demonstrates a Java-based railway management application with a graphical user interface and practical implementation of Object-Oriented Programming concepts.
