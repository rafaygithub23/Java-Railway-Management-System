# Java-Railway-Management-System
A JavaFX-based Railway Management System for managing trains, passengers, staff, tickets, and railway operations.


## About the Project

Railway Management System is a JavaFX-based desktop application designed to manage basic railway operations, including passengers, trains, railway staff, tickets, and user accounts.

The project was developed with the assistance of AI tools and configured and run using the JavaFX SDK.

## Technologies Used

- Java
- JavaFX
- Object-Oriented Programming
- File Handling
- Exception Handling
- IntelliJ IDEA
- JavaFX SDK

## Features

- Passenger management
- Train management
- Railway staff management
- Ticket management
- User authentication
- Admin functionality
- File-based data storage
- JavaFX graphical user interface
- Exception handling

## Project Purpose

This project demonstrates a Java-based railway management application with a graphical user interface and common Object-Oriented Programming concepts.

AI tools were used to assist with the development and implementation of the project.
